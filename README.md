🧙‍♀️ AI Gamebook Generator
An AI-powered tool that generates interactive choose-your-own-adventure style gamebooks using Meta's LLaMA language model.
This project combines natural language generation, narrative branching, and prompt engineering to create unique, immersive story experiences — ideal for fantasy, sci-fi, horror, and more.

💡 Built as part of my master's thesis exploring generative language models in creative applications.

🎯 Features
✍️ Dynamic story generation with rich, consistent worldbuilding

🧠 Based on LLaMA (Meta AI's large language model)

🔀 Branching narrative logic: multiple story paths and endings

🎮 Optional interactive demo (Streamlit or CLI)

📦 Modular codebase for easy extension and experimentation



🚀 How It Works
Prompt template defines the setting and tone of the story

User choices are fed back into the model to continue the narrative

Branching logic is tracked to build a coherent tree of events

Final output is compiled into a playable gamebook-style document (Markdown or HTML)
